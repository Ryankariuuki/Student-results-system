# Student Result System

A simple student result system developed using Python and Java.

## Project Overview

This project demonstrates basic programming concepts by creating a simple system that accepts student information and processes it.

The project contains implementations in two programming languages:

- Python
- Java

## Technologies Used

- Python
- Java
- Visual Studio Code

## Project Structure
StudentResultSystem/
├── java/
│   └── main.java
├── python/
│   └── app.py
└── README.md

## Java Version

The Java program uses Scanner to accept the student's name and display the entered information.

## Python Version

The Python program provides the student result functionality implemented in Python.

## Purpose

This project was created as a programming practice project to strengthen understanding of:

- Variables
- User input
- Data processing
- Basic programming logic
- Python programming
- Java programming
